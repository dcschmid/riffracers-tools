# riffracers-tools

Werkzeuge für die Riff-Racers-Vorproduktion.

- [`world-create/`](world-create/) – gemeinsame, wiederverwendbare Programme für Welten und Strecken: Layout, Validierung, Blueprints, Render, Grading, MOSS-Concepts und Dokumente. Jede Welt und jede Strecke hat einen eigenen Ausgabeordner.

Anleitung und Aufrufbeispiele: [`world-create/README.md`](world-create/README.md).
